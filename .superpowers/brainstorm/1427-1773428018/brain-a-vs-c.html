A vs C — Same Data, Different Feel

Both show the same "Acute Alarm" state. Which one feels more like Goblin DBT?

A — Abstract Network

Pros: Feels unique, modern, app-native. No one else has this. Nodes can animate (pulse, grow). Works great on mobile — no tiny anatomical details.

Cons: Users won't know where these structures physically are. Less educational about actual brain anatomy. Could feel too abstract for some users.

C — Hybrid (Brain + Network)

Pros: Users learn where things are in their brain. Feels grounded in real science. The outline gives context without being textbook-y. Still has the network glow.

Cons: Brain outline can feel clinical. Harder to render well on small screens. Labels get cramped in anatomical positions. Less "wow" factor.

My recommendation: A

The brain outline in C adds anatomical grounding, but at the cost of cramped labels on mobile and a slightly more clinical feel. Since you're building the standalone "My Brain" explorer as a separate feature, that's where the anatomical detail can really shine — with room to zoom, tap, and explore.

The post-check-in moment is about quick emotional insight, not anatomy class. Option A gives you a clean, animated, mobile-friendly visualization that says "here's what's active in your brain right now" without requiring the user to parse a brain diagram while they're in distress. The info bar underneath ("Salience Network — overactive") does the heavy lifting. And it looks like nothing else out there.

Use A for post-check-in, save the anatomical detail for the explorer.
